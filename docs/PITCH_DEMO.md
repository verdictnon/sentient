# Демо на Pizza Pitch

Этот сценарий показывает Sentient за три минуты на обычном ноутбуке. Видео, модели
и GPU не нужны: работает симулированный магазин. Интернет нужен только при первом
запуске.

## Накануне

1. Нужен Python 3.12 или новее.
2. Запустите демо один раз, пока есть интернет:

   ```sh
   run_demo.bat        # Windows
   ./run_demo.sh       # macOS или Linux
   ```

   Первый запуск ставит зависимости и собирает магазин. На чистой копии под Linux
   это заняло 100 секунд, Python-окружение весит около 380 МБ. Под Windows запуск
   ещё не проверялся, поэтому пройдите его заранее.
3. Запишите экран на две минуты: это запасной план, если ноутбук подведёт на сцене.

## Утром в день показа

1. Запустите с `--rebuild`, чтобы последним днём в данных стало настоящее вчера:

   ```sh
   run_demo.bat --rebuild
   ```

2. Откроется http://127.0.0.1:8766. Если порт занят, добавьте `--port 8770`.
3. Для проектора выберите светлую тему, белый фон читается лучше.
4. Язык переключается кнопкой EN/RU вверху. По умолчанию он берётся из браузера.
5. Чтобы чек напечатался на глазах у зала, обновите страницу (F5) прямо перед показом.

## Сценарий на три минуты

| Время | Экран | Что сделать | Что сказать |
| --- | --- | --- | --- |
| 0:00 | Магазин | Прочитайте заголовок вслух, покажите чек | Управляющий видит день одним предложением и одним Z-отчётом, как на кассе. |
| 0:30 | Магазин, карта | Переключите Тепло, Маршруты, Зоны. Нажмите «play» у ползунка часов | Камера уже висит в зале. Мы превращаем её в карту того, где люди ходят и останавливаются. |
| 1:00 | Магазин, «Что сделать дальше» | Покажите совет про вторую кассу | Система говорит, что сделать, и показывает числа, на которых основан совет. |
| 1:20 | Проверки | Нажмите «Открыть случаи», откройте случай «Ушёл мимо кассы», клип запустится сам | Подбор, за которым нет кассы, попадает на проверку с коротким клипом. Это повод посмотреть, а не обвинение. |
| 2:10 | Камеры | Нажмите «Запустить симуляцию» | Рамки и следы идут по записи, события появляются справа по ходу. |
| 2:40 | Магазин | Вернитесь клавишей 1, нажмите «Скачать PDF» | Отчёт готов к концу смены и не требует ручной работы. |

Клавиши 1–6 переключают экраны. Симуляция длится две минуты и продолжается, пока вы
на других экранах. Первое уведомление «ушёл мимо кассы» всплывает примерно через 56
секунд: если останетесь на камерах дольше, зал его увидит.

## Как говорить о данных

Жёлто-чёрная лента и пометка «Симуляция» на чеке входят в продукт. Не убирайте их и
скажите об этом сами: «Это симулированный магазин. Интерфейс и расчёты те же, что и
для настоящих записей».

| Можно сказать | Нельзя сказать |
| --- | --- |
| Это симулированный магазин, данные сгенерированы | Это данные реального магазина |
| Подбор без кассы становится поводом проверить запись | Система ловит воров |
| Касса здесь это зона в кадре камеры | Мы сверяем чеки с кассовой системой |
| Работает с записями на вашем компьютере | Подключается к камерам в реальном времени |
| Треки считаются в пределах одной камеры | Считаем уникальных покупателей |
| Точность на реальных магазинах ещё предстоит измерить | Точность 97% |

Цифра 97,3% относится к отобранным окнам RetailAction для разработки. На записях
с настоящих камер точность не измерялась, поэтому называть её нельзя.

«На проверке» на чеке это число подборов без кассы, умноженное на среднюю цену товара.
В демо цена условная, 1 800 ₸. Для настоящего магазина она задаётся в «Система и модели».
Эта сумма оценивает объём проверки, а не подсчитанный убыток.

## Если спросят

**Сколько клиентов уже используют?** Отвечайте только фактами о своей команде. В этом
репозитории нет данных о пилотах.

**Какая точность?** Детектор и модель подбора работают на записях, но на размеченных
данных из реальных магазинов точность ещё не измерена. Это следующий шаг.

**Куда уходит видео?** Никуда. Всё работает на компьютере магазина. Треки анонимны,
лица не распознаются.

**Это законно?** Мы не проверяли требования к видеонаблюдению и персональным данным.
Не утверждайте соответствие законам без юриста.

**Нужны новые камеры?** Sentient работает с записями обычных камер. Прямого подключения
к потоку камеры пока нет.

**Нужен GPU?** Для демо нет, симуляция заменяет модели. На настоящих записях нужны
детектор и модель подбора. В репозитории их нет, а разработка шла на RTX 4050.
